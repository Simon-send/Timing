# Sport icons

- `cross_country.svg`: supplied by the user as `openicons-cross-country-skiing-99061.svg`. The two background/frame paths were removed; the skier paths are preserved.
- `biathlon.svg`: vector recreation of the skating pose and rifle approved in the design conversation.

Both icons have transparent backgrounds and use one foreground color, tinted by the app theme. Labels and accessibility remain on the sport selector buttons.
